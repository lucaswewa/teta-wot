# Tutorial

This tutorial goes from nothing to a server of your own Things.

1. [Installing teta-wot](installing.md): the Rust toolchain, and depending on `wot`.
2. [Running a server](running.md): serving Things from a LabThings configuration file, with LabThings' command line.
3. [Writing a Thing](writing_a_thing.md): LabThings' tutorial light, with properties, an action and a functional property.

It is meant for someone writing Thing code for a new instrument, who may already know LabThings in Python. The [migration guide](../migration.md) maps the Python constructs to the Rust ones.
